# 🎹 PianoVerse

لعبة بيانو تفاعلية بالكامل HTML/CSS/JS بدون أي مكتبات خارجية أو ملفات صوت جاهزة — كل الأصوات بتتولّد لحظيًا عن طريق Web Audio API.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والشاشات الثلاث (القائمة / اللعب / النتائج) |
| `style.css` | الهوية البصرية (أسود فاخر + ذهبي + بنفسجي + سماوي) |
| `notes.js` | حساب الترددات الموسيقية + مكتبة الألحان لكل وضع |
| `instruments.js` | محرك التوليف الصوتي — 8 آلات موسيقية مختلفة |
| `game.js` | منطق اللعبة: الشاشات، لوحة المفاتيح، النقاط، المؤقّت |

## الأوضاع الخمسة
- **Classic** — مقطوعات كلاسيكية معروفة (Ode to Joy، Für Elise) + تدريب سلّم دو الكبير
- **Folk** — ألحان شعبية تراثية (فرنسا، أمريكا)
- **International** — ألحان من ست دول، وفيها مقطوعة أصلية باسم "Nile Nights" على مقام الحجاز
- **Freestyle** — عزف حر بدون تسجيل نقاط
- **Challenge** — نوتة عشوائية مولّدة في كل مرة، بمؤقّت زمني ضاغط

## الآلات الثمانية
بيانو، كمان، فلوت، ترومبيت، جيتار، إكسيلوفون، هاربسيكورد، أجراس — كل واحدة بمعادلة توليف صوت مختلفة (نوع الموجة + مغلّف ADSR + فلاتر) مش عينات صوت جاهزة.

## التحكم
- كليك أو لمس على المفاتيح مباشرة
- أو لوحة المفاتيح: `A S D F G H J K L` للمفاتيح البيضاء، `W E T Y U` للمفاتيح السوداء

## التشغيل
افتح `index.html` في أي متصفح مباشرة، أو ارفع الفولدر على استضافة استاتيك (GitHub Pages، Pterodactyl، إلخ) — مفيش أي backend مطلوب.
